# Screenshots

Place project screenshots in this directory for the README documentation.

## Recommended Captures

### From `reports/figures/` (copy after running pipelines)

```bash
cp reports/figures/correlation_heatmap.png docs/screenshots/01_correlation_heatmap.png
cp reports/figures/burnout_risk_distribution.png docs/screenshots/02_burnout_distribution.png
cp reports/figures/ai_usage_distribution.png docs/screenshots/03_ai_usage_burnout.png
cp reports/figures/model_comparison_metrics.png docs/screenshots/04_model_comparison.png
cp reports/figures/confusion_matrices.png docs/screenshots/05_confusion_matrices.png
cp reports/figures/feature_importance.png docs/screenshots/06_feature_importance.png
```

### From Streamlit App (manual screenshots)

1. Run `streamlit run app/streamlit_app.py`
2. Capture the welcome screen → `07_streamlit_home.png`
3. Capture the sidebar form → `08_streamlit_sidebar.png`
4. Submit a prediction → `09_streamlit_prediction.png`
5. Capture charts section → `10_streamlit_charts.png`
6. Capture recommendations → `11_streamlit_recommendations.png`
